# NEON LANES (placeholder name)

A 3D endless night-highway racer for the browser that installs as an iPhone PWA.
Plain JavaScript + [Three.js](https://threejs.org) (vendored in `vendor/`, no build step, works offline).

The game name is the constant `GAME_NAME` in `src/config.js`. After changing it run `node tools/build.mjs --art`
(regenerates the manifest, page title, splash screens and the offline cache list).

## Run it

Any static file server works (ES modules need `http://`, not `file://`):

```bash
cd highway
python3 -m http.server 8123       # or: npx serve .
# open http://localhost:8123/
```

Desktop keys: `← →` / `A D` change lane, `Space` / `↑` / `Shift` nitro, `P` / `Esc` pause, `Enter` start / retry.
On a phone: pick **Buttons**, **Wheel** or **Swipe** in *Settings*. The nitro button is available in every style.

## Install on iPhone

The PWA must be served over **HTTPS** (service workers do not run on plain `http://` except `localhost`).
Host the `highway/` folder anywhere static (GitHub Pages, Netlify, Vercel, Cloudflare Pages...). With GitHub Pages
enabled for this repo it lives at `…/highway/`.

1. Open the URL in **Safari** (iOS 16.4+ recommended).
2. Tap **Share** → **Add to Home Screen** → **Add**.
3. Launch it from the home screen: full-screen, splash screen, works offline after the first load.

Updates: when you deploy a new version the service worker (re-generated by `node tools/build.mjs`, versioned by a
content hash) installs it in the background; the game reloads itself the next time you are on a menu screen.

### Swapping in real 3D models later
All visuals come from `src/models.js`. `models.createVehicle(spec, color)` must return a `THREE.Group` with its origin on the
ground, nose towards −Z, and `userData.length/width/height`. To use a glTF car, register a builder for a body type:

```js
import { models } from './models.js';
models.register('car', 'mycar', (spec, colorOverride) => gltfClone.clone());   // spec.body === 'mycar'
```
Then set `model: { type: 'car', body: 'mycar', length, width, height }` in `src/data/cars.js`. Buildings/street lights use
`createBuildingKit` / `createStreetlightKit` the same way.

## Add a car
Append an object to `CARS` in `src/data/cars.js` (it appears in the garage automatically):

```js
{ id: 'rocket', name: 'Rocket', tier: 'sport', price: 30000,        // tier: regular | sport | luxury | formula
  topSpeed: 330, accel: 35, handling: 0.7, comboMult: 1.2, nitro: 1.3,   // km/h, km/h per s, 0..1, x, x
  weight: 1.5,        // optional: heavy = slower but smooth lane changes
  twitchy: true,      // optional: lane changes overshoot (Formula style)
  model: { type: 'car', body: 'sport', color: 0xff5500, length: 4.5, width: 1.9, height: 1.15 } }
```
Bodies: `sedan sport limo suv van truck formula`. For an **event-only** car omit the price and add `event: '<event id>'`.

## Add a world
Add an entry to `WORLDS` in `src/data/worlds.js` (copy `neoncity`). It shows up in the menu world picker. Fields: sky/fog/ambient colours,
road colours, `lanes` (`dir: 1` same direction, `-1` oncoming, `speed` m/s), `buildings`, `streetlights`, `coinBonus`,
`structure: 'city' | 'tunnel'`, and optional `rain: { count, color, speed }`, `wet: true`, `lightning: true`.
New structures (e.g. a bridge) are one more `_buildX()` method in `src/world.js`.

## Add an event
Add an object to `EVENTS` in `src/data/events.js` – the calendar, countdowns, goals, rewards and coin modifiers are generic:

```js
{ id: 'night_sprint', name: 'Night Sprint', color: '#ff2e9a', blurb: 'Reach 280 km/h in the tunnel.',
  schedule: { anchor: '2026-11-02', everyDays: 14, durationDays: 5 },     // repeating, or { start:'2026-12-01', end:'2026-12-24' }
  world: 'tunnel',
  goal:   { stat: 'maxKmh', type: 'max', target: 280, text: 'Reach {n} km/h' },   // stats: closeCalls tightCalls maxKmh score bestCombo distanceKm
  reward: { coins: 3000, car: 'my_event_car' },                                 // car must have event: 'night_sprint'
  modifiers: { coinMult: 1.5 } }                                                // add global: true to apply to every run
```

## Other tuning
* Balance (score, combo, nitro, hits): `SCORE` / `NITRO` / `CFG` in `src/config.js`. Economy and upgrades: `src/data/upgrades.js`.
* Daily missions: `src/data/missions.js`.
* Quality levels (`low` no post-processing, `medium` speed blur, `high` bloom + MSAA) live in `src/effects.js`; the game also lowers
  render resolution automatically (down to 55%) when frames get slow.

## Tests
No framework – headless scripts drive the real game with Playwright (`tools/shot.mjs`, `tools/t*.mjs`, `tools/offline.mjs`).
Example: `SCRIPT=$PWD/tools/t4.mjs node tools/shot.mjs http://localhost:8123/index.html /tmp/shot 844x390`.
